# Changelog

All notable changes to the Lab Skills GitHub Copilot Plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-05

### Added
- Initial release of GitHub Copilot plugin converted from lab-skills-v2
- Comprehensive workspace instructions in `.github/copilot-instructions.md`
- 3-tier skill architecture support (Meta-Governance, Meta-Methodology, Technical Skills)
- 6-phase lab methodology workflow
- Stack-specific guidance for Laravel 11, Alpine.js, Tailwind CSS, Preline UI
- File organization standards for academic labs
- Quality and security standards enforcement
- Granularity rules for skill engineering
- ADR (Architecture Decision Record) template
- Checkpoint law for phase transitions
- Windows environment optimizations
- Multi-language conventions (English code, French A1 presentation notes)

### Skills Included
- `lab-dev` - Meta-methodology for workflow guidance
- `plugin-dev` - Meta-governance for skill design
- `lab-skill-engineering` - IA architecture analysis

### Documentation
- Complete README.md with quick start guide
- Usage examples for common scenarios
- Contributing guidelines for creating new skills
- File organization templates
- Quality checklist and Definition of Done

### Technical Details
- Converted from Claude Code `.agent/skills/` format to GitHub Copilot workspace instructions
- Maintains SSOT (Single Source of Truth) principles
- Follows DRY (Don't Repeat Yourself) patterns
- Compatible with VS Code, JetBrains IDEs, and other Copilot-enabled editors
