## Phase 1 : Cadrage & Appropriation
- [ ] **Tâche 1.1 :** Lire le fichier `README.md` préparé par l'IA.
- [ ] **Tâche 1.2 :** Compléter les informations de votre projet fil rouge et prototype dans `README.md`.

## Phase 2 : Compétence IA Spécialisée (Synergie plugin-dev)
- [ ] **Tâche 2.1 :** Identifier le problème technique à résoudre dans la stack.
- [ ] **Tâche 2.2 :** Définir le nom et la mission du Skill IA nécessaire.
- [ ] **Tâche 2.3 :** Lancer `plugin-dev` pour créer le skill technique aux normes Anthropic.
- [ ] **Tâche 2.4 :** Vérifier que le skill technique passe la validation (`validate-skills.cjs`).

## Phase 3 : Rédaction & Implémentation du Lab
- [ ] **Tâche 3.1 :** Ouvrir le squelette de Lab généré (`Lab-[Nom].md`).
- [ ] **Tâche 3.2 :** Remplir l'explication théorique et justifier le choix de la solution technique.
- [ ] **Tâche 3.3 :** Coder l'étape 1 (Backend / Modélisation) en utilisant le skill technique.
- [ ] **Tâche 3.4 :** Coder l'étape 2 (Interface UI avec Preline UI) en utilisant le skill technique.
- [ ] **Tâche 3.5 :** Coder l'étape 3 (Dynamisme Alpine.js) en utilisant le skill technique.
- [ ] **Tâche 3.6 :** Tester le fonctionnement dans le navigateur (aucune erreur console).

## Phase 4 : Préparation de la Présentation (Sprint devant Formateur)
- [ ] **Tâche 4.1 :** Remplir la page de garde complète dans `Presentation-[Nom].md`.
- [ ] **Tâche 4.2 :** Vérifier les diapositives 1 à 5.
- [ ] **Tâche 4.3 :** Vérifier que chaque slide contient **exactement 3 phrases simples en français A1** dans les notes de l'orateur.
- [ ] **Tâche 4.4 :** Faire auditer et valider le lab par `lab-dev`.

## Phase 5 : Soutenance en Sprint en Direct
- [ ] **Tâche 5.1 :** Présenter les diapositives en lisant les notes orales en français A1.
- [ ] **Tâche 5.2 :** Réaliser la démonstration en direct (5 minutes max).
- [ ] **Tâche 5.3 :** Réussir le mini-défi technique demandé par le formateur.
