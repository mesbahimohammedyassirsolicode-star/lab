# Lab - Introduction aux Labs et Stack Technique

## 📋 Objectifs du Lab

- Comprendre ce qu'est un Lab et son utilité
- Découvrir la stack technique du projet
- Identifier les langages, frameworks et outils utilisés
- Établir le lien entre les Labs et le projet technique

## 🎯 Compétences visées

- Capacité à identifier les technologies d'un projet
- Compréhension de l'architecture technique
- Méthodologie d'apprentissage par la pratique

## 📚 Prérequis

- Notions de base en développement web
- Curiosité et volonté d'apprendre

## 🚀 Déroulement du Lab

### Partie 1 : Découverte du concept de Lab (20 min)

#### C'est quoi un Lab ?
Un Lab (laboratoire) est un exercice pratique et ciblé qui permet de :
- Découvrir un outil ou une technologie spécifique
- Tester une solution technique dans un environnement contrôlé
- Expérimenter sans impacter le projet principal
- Valider une approche avant son intégration

#### Pourquoi réaliser des Labs ?
- **Apprentissage progressif** : Maîtriser chaque composant séparément
- **Réduction des risques** : Tester avant d'intégrer
- **Documentation vivante** : Créer des références pour l'équipe
- **Montée en compétence** : Développer son expertise technique

#### Lien avec le projet technique
- Chaque Lab correspond à une fonctionnalité du projet
- Les Labs permettent de dérisquer les choix techniques
- Ils servent de POC (Proof of Concept) avant l'implémentation finale
- La somme des Labs constitue les briques du projet complet

### Partie 2 : Découverte de la Stack Technique (30 min)

#### Langages
- **PHP** : Développement côté serveur, en natif et avec Laravel
- **Kotlin** : Langage moderne pour Android et le backend
- **JavaScript** : Langage pour le développement web

#### Frameworks, UI et outils
- **Laravel** : Framework PHP
- **Alpine.js** : Framework JavaScript léger et réactif
- **Tailwind CSS** : Framework CSS utility-first
- **Preline UI** : Composants d'interface basés sur Tailwind CSS
- **VS Code** : Éditeur de code
- **Git et GitHub** : Gestion de versions et collaboration
- **Antigravity** : Environnement de développement assisté par IA
